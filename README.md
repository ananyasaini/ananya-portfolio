# Ananya Saini — Design Portfolio

A responsive portfolio for Ananya Saini, a visual communication and UI/UX designer working across digital products, campaigns, brand systems, internal communication, and spatial experiences.

## Highlights

- Interactive selected-work gallery for product and visual-design projects
- Responsive layouts for desktop, tablet, and mobile
- Format-aware artwork presentation for case studies, carousels, flyers, and standees
- Professional experience, preferred tools, and personal profile sections
- Accessible keyboard navigation and reduced-motion support

## Built with

- React 19
- Next.js-compatible Vinext runtime
- TypeScript
- CSS animations and responsive layout
- Vite and Cloudflare-compatible output

## Local development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open the local address printed by the development server.

## Verification

```bash
npm run build
npm test
```

## Deployment

The intended production target is Vercel. Import this GitHub repository from the `main` branch, use Node.js 22.13 or newer, and confirm the framework and build settings during the deployment setup.
